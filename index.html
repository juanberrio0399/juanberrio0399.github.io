01 — Profile

Engineer who ships, not just reports

I'm a Cloud & Data Engineer with 6+ years building and automating the platforms that run data in production. I don't just process the data — I build the serverless infrastructure that produces, stores and serves it, with Infrastructure as Code and CI/CD.

My current project incrementally ingests an international courier's Excel files, consolidates them into a DuckDB warehouse, and publishes a serverless dashboard (Cloudflare + React + DuckDB-WASM) that updates itself three times a day — with no server to maintain and ~$0 infrastructure.

I design with an architecture mindset: separating compute, storage and presentation, choosing serverless, and optimizing for cost. Currently advancing on AWS and Systems Engineering, on the path to Cloud Solutions Architect.

DataForge Cloud

Production

A serverless analytics platform: business data ends up as a self-updating cloud dashboard, with no backend and ~$0 infrastructure.

How I automate it
  • Incremental ingestion — only the files that changed get reprocessed (catalog-based control).
  • The fresh result is auto-published to Cloudflare R2 (object storage).
  • A serverless dashboard queries the data directly in the browser (DuckDB-WASM) — no server, no database to host.
  • Scheduled 3×/day (Task Scheduler + GitHub Actions) with failure isolation: a cloud hiccup never breaks the local run.

Impact: analytics that update themselves, no server to maintain, ~$0 infrastructure.

DataForge

Production

The ETL engine behind the platform — it turns thousands of business Excel files into a clean, queryable warehouse.

How I automate it

Serverless RAG Assistant

Live · AI

An AI assistant that answers questions grounded in your own documents — 100% serverless on Cloudflare. Deployed and live.

How I automate it
  • RAG: documents → chunks → embeddings → Vectorize (vector DB); on a question it retrieves the closest chunks and an LLM answers.
  • Runs on Cloudflare Workers AI — no server, no database to host, ~$0 infrastructure.
  • Prompt-engineered guardrail: anti-hallucination (says "I don't know" when the answer isn't in the docs), multilingual, source tracking.
  • Infrastructure as Code (Terraform) + CI/CD.
