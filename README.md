# juanberrio0399.github.io

Interactive portfolio of **Juan Berrio** — Cloud & Data Engineer.

🔗 Live: https://juanberrio0399.github.io

Single-file static site (HTML + CSS + vanilla JS): animated canvas network background,
typewriter roles, scroll-reveal animations, animated counters and an EN/ES language toggle.
No build step — served directly by GitHub Pages.

## Future Architecture: Local-First Data Portfolios

To demonstrate zero-egress processing and cloud cost efficiency (FinOps), upcoming dashboard iterations will transition static metrics to client-side data processing using **Apache Arrow** and **Arquero**.

### Technical Viability & Stack
- **Apache Arrow / Arquero:** Enables blazing-fast columnar query processing directly in the browser via WebAssembly, capable of handling 100k+ rows instantly without server roundtrips.
